    About SRG Calendar Pro

    SRG Calendar Pro

    Version v1.0.0 (Local DB PWA)

    SRG Calendar Pro (Local DB) is a standalone, single-device Progressive Web App featuring full offline scheduling (Month, 30-Day Portrait Table, Day, Agenda), travel transit tracking, daily notes, double-entry financial statements, and local attachment archives.

    Built with SQLite WASM and browser IndexedDB storage. Operates 100% offline on any device without requiring PHP or an external server.

    Developer: S. Rathinagiri
    Storage: Local SQLite WASM & IndexedDB
    Platform: Offline PWA (Single-Device)
