    About Calendar App

    Calendar App

    Version v1.2.7 (PWA)

    Calendar App is a standalone, single-device Progressive Web App featuring full offline scheduling (Month, 30-Day Portrait Table, Day, Agenda), travel transit tracking, daily notes, double-entry financial statements, and local attachment archives.

    Built with SQLite WASM and browser IndexedDB storage with hardware-accelerated Web Crypto AES-256 database encryption at rest. Operates 100% offline on any device without external servers.

    Developer: S. Rathinagiri
    Security: AES-256-GCM Encrypted at Rest
    Storage: Local SQLite WASM & IndexedDB
    Platform: Offline PWA (Single-Device)
